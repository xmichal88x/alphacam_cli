# CLI Tests with Mocked COM — Implementation Plan

> **Task:** Dodać 20 testów CLI z mockowanym COM do `tests/unit/test_cli.py`

**Goal:** Rozszerzyć istniejący plik testowy o 20 testów rzeczywistej logiki CLI z mockowanym COM.

**Architektura:** Wykorzystuje istniejącą fixture `mock_com` z `tests/conftest.py`, która mockuje `win32com.client.Dispatch` i `win32com.client.GetActiveObject`. Każdy test mockuje `require_platform()` aby ominąć sprawdzanie platformy. Testy walidacji (depth/speed) działają bez mock_com, bo walidacja jest przed `require_platform()`.

**Tech Stack:** Python 3.11+, pytest, typer.testing.CliRunner, unittest.mock

**Kluczowe wzorce mockowania:**

```python
# Dla testów COM (większość):
def test_command(mock_com):
    with patch("alphacam_cli.cli.common.require_platform"):
        result = runner.invoke(app, ["command", "args"])
        assert result.exit_code == 0
        assert "expected text" in result.stdout

# Dla testów z geometriami — konfiguracja mocka:
def test_mill_rough(mock_com):
    app_mock = mock_com.return_value
    app_mock.ActiveDrawing.Geometries.Count = 3
    with patch("alphacam_cli.cli.common.require_platform"):
        result = runner.invoke(app, ["mill", "rough", "-d", "-10", "-s", "12000"])

# Dla testów walidacji (bez COM):
def test_validation():
    result = runner.invoke(app, ["mill", "rough", "--depth", "5"])
    assert result.exit_code == 2

# Dla NC output (mockowanie os.path.exists + open):
def test_nc_output(mock_com):
    m = mock_open(read_data="N100 G0 X0 Y0\n")
    with patch("alphacam_cli.cli.common.require_platform"), \
         patch("os.path.exists", return_value=True), \
         patch("builtins.open", m):
        result = runner.invoke(app, ["nc", "output", "test.nc"])
```
