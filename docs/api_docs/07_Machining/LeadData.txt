LeadData Object

LeadData Object

An object used to set the values for Lead-In/Out in 
 a Machining Style.

 

Properties

 

Angle - (float) Angle for 
 lead-in/out in degrees

 

LeadIn - (AcamLeadType) acamLeadLINE, 
 acamLeadARC, acamLeadBOTH, acamLeadNONE, acamLeadNO_CHANGE or acamLeadBOTH_NOT_TANGENTIAL

 

LeadOut- (AcamLeadType) acamLeadLINE, 
 acamLeadARC, acamLeadBOTH, acamLeadNONE, acamLeadNO_CHANGE or acamLeadBOTH_NOT_TANGENTIAL

 

LengthIn - (float) Length 
 of lead-in line

 

LengthOut - (float) Length 
 of lead-out line

 

LineArcInTangential - (Bool) 
 True if lead-in line and arc are to be tangential. (acamLeadBOTH only)

 

LineArcOutTangential - (Bool) 
 True if lead-in line and arc are to be tangential. (acamLeadBOTH only)

 

Radius - (float) Radius of 
 arc

 

SlopeIn - (Bool) True if lead-in 
 is to be sloping

 

SlopeOut - (Bool) True if 
 lead-out is to be sloping
