PLIK: AfterOpenFileEvent
================================================================================

AfterOpenFile Event
 
 

 AfterOpenFile Event

 Sub AfterOpenFile (FileName As String)

 Called after AlphaCAM has opened an AlphaCAM drawing. FileName is the complete path name of the file that has been opened.

 The example will write the name of each opened file to a log file, along with the date and time when it was opened:

  Sub AfterOpenFile (FileName As String)

    SysDate$ = Date

    SysTime$ = Time

    Open "c:\temp\log.txt" For Append As #1

    Print #1, SysDate$, ", ", SysTime$, " - Opened - ", FileName

    Close #1 

  End Sub

PLIK: AfterSelectToolEvent
================================================================================

AfterSelectTool Event
 
 

 AfterSelectTool Event

 Sub AfterSelectTool (Tool As MillTool)

 Called after AlphaCAM has selected a tool.

 Tool is an object variable representing the selected tool. It may be used to inspect and/or modify the properties of the tool.

 For example:

  Sub AfterSelectTool (Tool As MillTool)

   If Tool.Number = 55 Then

    Tool.FixedSpeed = 500

    Tool.FixedFeed = 65

   End If

  End Sub

PLIK: BeforeChangeTool_Event
================================================================================

BeforeChangeTool Event

BeforeChangeTool Event

Function BeforeChangeTool As String

Called before AlphaCAM shows tool selection dialog box 
 when the "Change" button is clicked in a machining dialog box. 
 

A string should be returned. There are three possible 
 forms of return string:

BeforeChangeTool = "0"

AlphaCAM will call the BeforeSelectTool 
 event.

BeforeChangeTool = filename

AlphaCAM will use the tool in the given file name. This 
 should be a file produced by the Machine 
 / Define Tool command in AlphaCAM.

BeforeChangeTool = "2"

AlphaCAM will do nothing. It is assumed that the script 
 will create and select a tool using the Application.CreateTool 
 method, as in the example:

Function BeforeChangeTool As String

 Dim Tool As MillTool

 Set Tool = App.CreateTool

 With Tool

  .type = acamToolBALL

  .name = "T82, Ball, 
 Dia 15"

  .number = 82

  .feedpertooth = .1

  .diameter = 15

  .length = 50

 End With

 Tool.Select

 BeforeSelectTool = "2"

End Function

PLIK: BeforeCloseEvent
================================================================================

BeforeClose Event
 
 

 BeforeClose Event

 Function BeforeClose

 Called before AlphaCAM clears memory (complete clear ie All Layers, or New command) or exits.

 If you want to prevent Clear or Exit eg because you have something in memory that is not saved, you can display a message box warning the user, saving it if necessary.

 A number should be returned. There are two possible return values:

 BeforeClose = 0

 AlphaCAM will Clear or Exit.

 BeforeClose = 1

 The current command will be cancelled.

PLIK: BeforeConicCuts_Event

BeforeConicCuts Event (Wire only)

BeforeConicCuts Event (Wire only)

Function BeforeConicCuts

Called before AlphaCAM does the Conic Cuts command when 
 the user has selected the Machine / Conic 
 Cuts command.

A number should be returned. There are two possible 
 return values:

BeforeConicCuts = 0

AlphaCAM will do the normal command.

BeforeConicCuts = 1

AlphaCAM will do nothing - your routine should do everything required for the command 
 - show dialog box(es), select geometries, make the tool paths etc.

For example:

 Function BeforeConicCuts

  ' Do my code for special cuts

  BeforeConicCuts = 1

 End Function

PLIK: BeforeCreateNcEvent
================================================================================

BeforeCreateNc Event

BeforeCreateNc Event

Function BeforeCreateNc

Called before AlphaCAM creates the NC code, for any 
 reason, for example: List NC, Output NC, or called from the API.

This may be used to set post variables or attributes, 
 for example. This event should be used in preference to BeforeOutputNc, 
 because BeforeOutputNc is only 
 called if a file name is required.

Use AfterCreateNc 
 to reset anything if necessary.

A number should be returned. There are two possible 
 return values:

BeforeCreateNc 
 = 0

AlphaCAM will continue the command.

BeforeCreateNc 
 = 1

The current command will be cancelled.

BeforeDefineTool Event
 
 

 BeforeDefineTool Event

 Function BeforeDefineTool

 Called before AlphaCAM shows the define tool dialog box when the user has selected the Machine / Define Tool command to define a tool.

 A number should be returned. There are two possible return values:

 BeforeDefineTool = 0

 AlphaCAM will show the normal define tool dialog box.

 BeforeDefineTool = 1

 AlphaCAM will do nothing - your routine should define a tool, maybe in an external program.

 For example:

  Function BeforeDefineTool

   App.ShellAndWait "mydefinetool.exe"

   BeforeDefineTool = 1

  End Function

BeforeEditTool Event
 
 

 BeforeEditTool Event

 Function BeforeEditTool (Tool As MillTool)

 Called before AlphaCAM shows the define tool dialog box when the user has clicked the Edit tool button in the Machine / Select Tool command to edit a tool.

 A number should be returned. There are three possible return values:

 BeforeEditTool = 0

 AlphaCAM will show the normal define tool dialog box.

 BeforeEditTool = 1

 Your routine may edit the tool, AlphaCAM will then save it.

 BeforeEditTool = 2

 AlphaCAM will do nothing, your routine can edit the tool and save it, or cancel, AlphaCAM will NOT save it.

PLIK: BeforeInputCadEvent
================================================================================

BeforeInputCad Event
 
 

 BeforeInputCad Event

 Function BeforeInputCad (CadType As Integer) As String

 Called before AlphaCAM shows the open file dialog box when the user has selected the File / Input CAD command to input a CAD file eg DXF.

 CadType is an integer giving the type of CAD file that the user has selected from the dialog box. It will have one of the following values:

 acamDXF

 acamDWG

 acamIGES

 acamCADL

 acamVDA

 acamANVIL

 acamXYZ

 acamSTL

 A string should be returned. There are three possible forms of return string:

 BeforeInputCad = "0"

 AlphaCAM will show the normal open file dialog box.

 BeforeInputCad = "2"

 The command will be cancelled.

 BeforeInputCad = filename

 AlphaCAM will use the given file name.

 For example:

  Function BeforeInputCad (CadType As Integer) As String

   If CadType = acamDXF Then

    BeforeInputCad = "C:\cadfiles\template.dxf"

   Else

    BeforeInputCad = "0"

   End If

  End Function

PLIK: BeforeOutputNcEvent
================================================================================

BeforeOutputNc Event
 
 

 BeforeOutputNc Event

 Function BeforeOutputNc As String

 Called before AlphaCAM shows save file dialog box when user has selected the File / Output NC command to save the NC code, and selected the File or Both option from the first dialog box.

 A string should be returned. There are three possible forms of return string:

 BeforeOutputNc = "0"

 AlphaCAM will show the normal save file dialog box.

 BeforeOutputNc = "2"

 The command will be cancelled.

 BeforeOutputNc = filename

 AlphaCAM will use the given filename.

 The example will create a filename, starting with prog1.nc, then prog2.nc, incrementing the number until a name is found which does not exist. If none are found the function returns "0" to show the normal dialog box:

 Function BeforeOutputNc As String

  For i = 1 To 9999

   fn$ = "C:\temp\prog" + str$(i) + ".nc"

   If dir(fn$) = "" Then

    ' File does not exist - return the name

    BeforeOutputNc = fn$

    Exit Function

   End If 

  Next i

  ' Give up

  BeforeOutputNc = "0"

 End Function

GetFeedsAndSpeedsButtonText Event
 
 

 GetFeedsAndSpeedsButtonText Event

 Function GetFeedsAndSpeedsButtonText As String

 If this function exists and returns a string, a button will be placed in the Feeds and Speeds dialog box in Rough / Finish, Drilling etc. The returned string will be used for the text of the button. If the button is clicked by the user the NewFeedsAndSpeed event will be called.

 For example, the following will enable the button and put the text "Tool Manager" in it.

 Function GetFeedsAndSpeedsButtonText As String

  GetFeedsAndSpeedsButtonText = "&Tool Manager"

 End Function

Introduction to Events

Introduction to Events

VBA Projects which are automatically loaded can gain 
 control when certain events happen in AlphaCAM.

Projects must have the correct extension for the module, 
 eg *.a?b (where ? specifies the 
 module type eg m = Mill, t = Turn etc) and must be in either the StartUp folder in the VBMacros 
 in the default Licomdir folder, 
 or in StartUp in the Alpha01 
 folder, or in SysMacro in the 
 Alpha01 folder. 

They may be prevented from loading using the Utils 
 | Add-Ins dialog box, unless in the SysMacro 
 folder.

For example, when the user selects a tool, a routine 
 in the project can be called which might get the tool from an external 
 database, ignoring the normal AlphaCAM tool library. As another example, 
 when the user selects the File | Open 
 command a routine can force a particular file to be used, suppressing 
 the open file dialog box.

All file names should include the full path and extension 
 eg "C:\licomdir\parts\62198754.amd"

The routine InitAlphacamAddIn 
 will be called when the VBA project is loaded when AlphaCAM starts. It 
 may be used to initialise data and add menu items, for example.

A DLL written in, for example, Delphi or C++ can also 
 handle events. See the comments in the source code samples.

Note: External programs (*.exe) will NOT handle events.

The project or DLL can handle as many or as few events 
 as desired. It must exist when the AlphaCAM module is executed. When the 
 user selects a command which causes one of the events, AlphaCAM looks 
 for a function with the name of the event. It 
 will only be looked for in a Module called Events. If found the function will be called.

PLIK: NewFeedsAndSpeedEvent

NewFeedsAndSpeed Event
 
 

 NewFeedsAndSpeed Event

 Sub NewFeedsAndSpeed (md As Object, tool As Object)

 Called when button in Feeds and Speeds dialog box clicked. (See GetFeedsAndSpeedsButtonText). 

 md is a MillData object whose properties may be modified if required eg DownFeed or CutFeed. Tool is the current tool, read-only ie its properties may be read but not changed.

 For example:

  Sub NewFeedsAndSpeed (md As MillData, tool As MillTool)

   md.cutfeed = 75

   md.spindlespeed = 950

  End Sub
