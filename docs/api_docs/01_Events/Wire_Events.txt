BeforeCut2AxisShape Event (Wire only)
 
 

 BeforeCut2AxisShape Event (Wire only)

 Function BeforeCut2AxisShape

 Called before AlphaCAM does the Cut 2-Axis Shapes command when the user has selected the Machine / Cut 2-Axis Shapes command.

 A number should be returned. There are two possible return values:

 BeforeCut2AxisShape = 0

 AlphaCAM will do the normal command.

 BeforeCut2AxisShape = 1

 AlphaCAM will do nothing - your routine should do everything required for the command - show dialog box(es), select geometries, make the tool paths (using WireData.Cut2AxisShape) etc.

 For example:

  Function BeforeCut2AxisShape

   ' Do my code for special cuts

   BeforeCut2AxisShape = 1

  End Function
