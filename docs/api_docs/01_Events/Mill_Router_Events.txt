AfterRoughFinish Event (Mill/Router only)
 
 

 AfterRoughFinish Event (Mill/Router only)

 Sub AfterRoughFinish (PS As Paths, Redo As Integer)

 Called after AlphaCAM has produced tool paths using the Rough / Finish command, or using the API (Redo = 0), or after the tool paths have been regenerated (with the Update Tool Paths command or Edit Operations) (Redo = 1).

 The tool paths will be passed as a Paths Collection.

 For example, the following routine will add an attribute to the new tool paths:

  Sub AfterRoughFinish (PS As Paths, Redo As Integer)

   Dim P As Path

   For Each P In PS

    P.Attribute("LicomUKDMBTest1") = "Test1"

   Next P

  End Sub

BeforeRoughFinish Event (Mill/Router only)
 
 

 BeforeRoughFinish Event (Mill/Router only)

 Function BeforeRoughFinish

 Called before AlphaCAM does the Rough / Finish command when the user has selected the Machine / Rough or Finish command.

 A number should be returned. There are two possible return values:

 BeforeRoughFinish = 0

 AlphaCAM will do the normal command.

 BeforeRoughFinish = 1

 AlphaCAM will do nothing - your routine should do everything required for the command - show dialog box(es), select geometries, make the tool paths (using MillData.RoughFinish) etc.

 For example:

  Function BeforeRoughFinish

   ' Do my code for special cuts

   BeforeRoughFinish = 1

  End Function
