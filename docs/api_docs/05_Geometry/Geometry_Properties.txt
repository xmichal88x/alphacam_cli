CircleProperties Example
 
 

 CircleProperties Example

 The example will loop for all the geometries in the drawing and display the diameter of each circle.

 Dim drw As Drawing 

 Set drw = App.ActiveDrawing 

 Dim p As Path 

 For Each p In drw.Geometries 

 Dim c As CircleProperties 

 Set c = p.GetCircleProperties 

 If Not (c Is Nothing) Then 

 MsgBox "Circle Diameter = " & c.diameter 

 End If 

 Next p

CircleProperties Object
 
 

 CircleProperties Object

 Object used to get the properties of a circle if a geometry represents a circle.

 Use Path.GetCircleProperties to get the object. If the geometry is a circle then this object will be returned and its properties may be read (not written). If it is not a circle the special value Nothing will be returned.

 Note: for this object, a circle is defined as an arc with an included angle of more than 270 degrees.

PLIK: Path_GetCircleProperties
================================================================================

Path.GetCircleProperties
 
 

 Path.GetCircleProperties

 Analyse path to see if it is a circle. If it is, return a CircleProperties object. The properties of the object may then be read (not written). If it is not a circle the special value Nothing will be returned.

 Note: for this method, a circle is defined as an arc with an included angle of more than 270 degrees.

 Syntax

 geo.GetCircleProperties

 [Return] CircleProperties   CircleProperties object , Nothing if geo is not a circle.

================================================================================
PLIK: Path_GetRectangleProperties
================================================================================

Path.GetRectangleProperties
 
 

 Path.GetRectangleProperties

 Analyse path to see if it is a rectangle (parallel to the X axis). If it is, return a RectangleProperties object. The properties of the object may then be read (not written). If it is not a rectangle the special value Nothing will be returned.

 Syntax

 geo.GetRectangleProperties

 [Return] RectangleProperties   RectangleProperties object , Nothing if geo is not a rectangle.
